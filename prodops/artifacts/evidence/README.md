# Evidence

Área reservada para evidências de entrega.

Evidências específicas de experimentos ficam em `prodops/journeys/discovery/experiments/<id>/evidence/`.

Evidências de Downstream são registradas no trail da sessão ativa em `prodops/artifacts/trails/sessions/YYYY-MM-DD-<session-id>.md` — ver [release-trail.md](../trails/release-trail.md) para a convenção de nome.
