## Intenção

Resultado esperado, conforme o OBC `webhook-configuration`:

> Magazine Siará pode registrar uma URL de webhook associada ao seu token de API e receber notificações automáticas a cada mudança de status de pagamento relevante, sem precisar consultar a Payments API ativamente. O sistema assina cada entrega com HMAC-SHA256 para que o receptor possa verificar a autenticidade. Ambientes locais funcionam sem configuração adicional de certificado.

---

## Contexto

Permite ao consumidor registrar endpoint e receber os eventos de pagamento. Associação ao sinal BS-003 inferida (ver BS-003).
