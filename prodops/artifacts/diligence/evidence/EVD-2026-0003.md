### Step 4 — Teste de idempotência (segundo POST)

**RESULTADO CRÍTICO: API NÃO É AUTO-IDEMPOTENTE.**

O segundo POST com `name="Workspace Reconciliation"` retornou HTTP 201 e criou uma
View duplicada com number=8 e node_id=PVTV_lADOAT1J1c4BeILXzgLFNOs.

Tentativa de deletar view #8:
- `DELETE /orgs/produtoreativo/projectsV2/24/views/8` → 404 Not Found
- GraphQL `deleteProjectV2View(input: {viewId: ...})` → Field doesn't exist on Mutation
- **Conclusão: Não existe mecanismo de deleção de Views via API.** Remoção requer Web UI manual.

## Resultado

**Classificação:** Partial Success

**Descrição:** A hipótese principal foi CONFIRMADA — REST POST cria Views com sucesso (HTTP 201).
No entanto, o experimento revelou dois findings críticos:

1. **API não é auto-idempotente**: Múltiplos POSTs com o mesmo `name` criam Views duplicadas
   sem retornar erro ou deduplicar. A idempotency_strategy documentada na matriz
   (GraphQL pre-check obrigatório antes de qualquer POST) é MANDATÓRIA para evitar duplicatas.

2. **DELETE não disponível via API**: Não existe endpoint REST nem mutation GraphQL para
   deletar Views. A View duplicada #8 criada pelo teste de idempotência persiste no
   GitHub Project e requer remoção manual via Web UI.

## Idempotência

**Resultado: FALHA** — A API não é auto-idempotente. O segundo POST criou uma View
duplicada (number=8, node_id=PVTV_lADOAT1J1c4BeILXzgLFNOs) sem retornar erro.

**Implicação arquitetural:** O script de automação DEVE implementar o padrão
`GraphQL pre-check → diff → POST somente se ausente` como passo obrigatório,
não opcional. Qualquer script que execute POST sem verificação prévia produzirá duplicatas.

## Conclusão técnica

A hipótese foi confirmada parcialmente:

- **CONFIRMADO:** REST POST /orgs/{org}/projectsV2/{project_number}/views cria Views (HTTP 201)
- **DESCOBERTO:** A API não é idempotente — duplicatas são criadas silenciosamente
- **DESCOBERTO:** Não existe DELETE para Views via API (REST nem GraphQL)
- **CLASSIFICAÇÃO MANTIDA:** Supported Automation — a classificação permanece correta.
  A ausência de idempotência nativa impede promoção para Native Automation
