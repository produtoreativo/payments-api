- Instrução em SKILL.md não seguida pelo agent em todas as phases — mitigado por especificar como requisito explícito.
- Trail no GitHub Issue diverge de trail em arquivo — mitigado pela decisão explícita no OBC: trail canônico no GitHub Issue comment.
