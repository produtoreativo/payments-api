### Why

- **Bootstrap events not in Datadog with iteration tag**: `send.sh` had no mechanism to include
  `iteration:<id>` tag. BDD requires this tag on every event. Fixed by adding `--iteration-id`
  parameter to `send.sh` and passing it from `emit-event`.

- **Test 06 idempotency failure**: The test omitted `iteration-id`, causing the system to look
  in the wrong timeline directory and not find the existing event. Fixed by adding `iteration-id`
  to match the scope used by test 01.

- **FINISHING state**: Confirmed working — `Delivery.Finish.Started` (catalog: `new-state: FINISHING`)
  correctly derives FINISHING through the full pipeline. Covered by new test 09.
