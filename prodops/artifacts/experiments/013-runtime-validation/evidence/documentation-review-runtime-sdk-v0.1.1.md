## Changes Implemented

### 1. `EventId` branded type — `src/models/event-id.ts`

**New file.** Branded `string & { readonly [_eventIdBrand]: 'EventId' }`.

- Format: UUID v7 (time-ordered monotonic, RFC 9562).
- Generated by Event Producer before any persistence. Maps 1:1 to `CloudEventEnvelope.id`.
- No domain semantics — opaque identifier. Never reused, even under `Event.Corrected`.
- Generation is **not** part of this SDK (no runtime dependency). Implementors use a `uuidv7` library.
- Cast `as EventId` in tests and examples.

**Impact:** `EventInstance.id` narrowed from `string` → `EventId`. Any code passing a plain string where `EventId` is expected now fails at compile time — correct behavior.


- Domain conceptual term vs schema-level term. Identical at runtime.
- Preferred in application-layer code (producers, consumers, examples).

### 3. `CloudEventSource` branded type — `src/contracts/cloud-events.ts`

Branded `string & { readonly [_sourceBrand]: 'CloudEventSource' }`.

- Represents the `source` field of a CloudEvents 1.0 envelope per spec §3.1.
- Format: absolute URI or URI-relative-reference.
- `CloudEventEnvelope.source` narrowed from `string` → `CloudEventSource`.
- Encoding: `event.producer_identity as CloudEventSource` — cast at the adapter boundary.

### 4. Enhanced OperationalStateEngine — `src/contracts/operational-state-engine.ts`

Added to the port contract:

| Addition | Description |
|---|---|
| `deduplicate(events)` | Removes events with duplicate `id`; returns new array, input not mutated. Idempotent. |
| `replayUntil(events, until)` | Replays events ≤ `until` (ISO-8601). Returns `DerivedState \| null`. |
| `stateHistory(events)` | Returns `StateHistory` — one `StateHistoryEntry` per state-altering event. |
| `StateHistoryEntry` | `{ state: DerivedState; causedBy: EventInstance }` |
| `StateHistory` | `{ workItemId: string; entries: ReadonlyArray<StateHistoryEntry> }` |

**Canonical OSE pipeline (documented in contract JSDoc and README):**
```
validate → deduplicate → order → applyCorrections → effectiveState / stateHistory
```

**Distinction preserved:**
- `lookback` = semantic alias for `replayUntil` — for audit/debugging contexts.
- `replayUntil` = temporal boundary replay for Timeline consumers.
