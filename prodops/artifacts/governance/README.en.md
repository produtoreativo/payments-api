# Governance

Artifacts that record how delivery is controlled and evidenced — iteration plans, historical release trails, and delivery evidence.

| Subdirectory | Content |
|---|---|
| [plans/](plans/) | Iteration Plan — active iteration plan with OBCs, BDDs, and acceptance criteria |
| [trails/](trails/) | Release Trail and sessions — immutable history of releases and delivery sessions |
| [evidence/](evidence/) | Delivery evidence — artifacts that prove OBCs were satisfied |
