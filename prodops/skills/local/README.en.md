# skills/local/

Reserved space for product-specific Skills.

Skills in this directory:

- Belong to this repository, not to the canonical ProdOps Framework.
- Must not be distributed to other products.
- A future Framework sync must preserve this entire directory.
- May consume Framework concepts, templates, and Skills.
- The Framework does not depend on them.

The `skills/local/` path convention is defined by the Framework.
The content is product ownership.
