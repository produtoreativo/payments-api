# skills/local/

Espaço reservado para Skills específicas do produto.

Skills neste diretório:

- Pertencem a este repositório, não ao ProdOps Framework canônico.
- Não devem ser distribuídas a outros produtos.
- Uma futura sincronização do Framework deve preservar este diretório inteiro.
- Podem consumir conceitos, templates e Skills do Framework.
- O Framework não depende delas.

A convenção do path `skills/local/` é definida pelo Framework.
O conteúdo é ownership do produto.
