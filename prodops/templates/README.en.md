# Templates — ProdOps

Reusable templates organized by work area.

Copy the template to the canonical location indicated before filling it in. Never fill in the template in place.

---

## Definition, template, and instance

| Concept | What it is | Where it lives |
|---|---|---|
| **Definition** | Structure and semantics of the artifact | `prodops/framework/` |
| **Template** | Empty structure ready to copy | `prodops/templates/` |
| **Instance** | Template filled with real data | `prodops/artifacts/` |

Filled instances belong in `prodops/artifacts/`, never in `prodops/templates/`.

## Product-local adaptations (`templates/local/`)

When the product needs to adapt a canonical template (e.g. checklist with product-specific gates, OBC with extra fields), the adaptation goes in `prodops/templates/local/`.

Rules:
- `templates/local/` belongs to the product, not to the canonical Framework.
- `templates/local/` is protected from sync by `.prodopsignore`.
- A canonical Skill cannot depend on a specific local template by name.
- A Product Skill may consume a local template.
- Filled instances never live in `templates/local/` — they go to `prodops/artifacts/`.

This product **has no local templates** at this time. The `templates/local/` directory will be created only when there is real content to place there.

---

## Dependency direction

```
Framework Skill  →  may use canonical template
Framework Skill  →  does not require a specific local template
Product Skill    →  may use canonical or local template
Template (empty) →  copied and filled → becomes an Artifact in prodops/artifacts/
```

---

## Rules

- Never fill in templates in place — copy to the canonical destination.
- Never create product or release artifacts here — templates are structure, not content.
- When evolving a template, check whether existing instances in the artifacts need to be migrated.
- Canonical templates do not depend on local adaptations.
- Relationship with Skills: see `prodops/skills/README.md`.
- Relationship with Artifacts: see `prodops/artifacts/README.md`.
