# Context Capsule

Canonical location: generated by the `/downstream` readiness gate at
`prodops/artifacts/iterations/<iteration-id>/cards/<card-slug>/context.md`.
Capsules are generated, not handwritten — regenerate via `/downstream`, never edit directly.

The capsule is the only artifact the agent needs to load in order to execute the full
CI Sync and CI Async flow without re-reading infrastructure files. Fields marked
`(filled by <phase>)` are left blank at generation time and filled at runtime.
