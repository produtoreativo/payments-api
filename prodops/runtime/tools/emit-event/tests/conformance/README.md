# Cross-Player Conformance Suite

Automated conformance checks for `prodops_emit_event` across Claude, Codex, and Copilot.

## Structure

```
conformance/
├── run-claude.sh         Claude player conformance run (22 checks)
├── run-codex.sh          Codex player conformance run (22 checks)
├── run-copilot.sh        Copilot player conformance run (22 checks)
├── compare-results.py    Cross-player comparison and report
├── expected/
│   └── bootstrap-started.json   Expected canonical output shape
└── results/              Generated by each run-<player>.sh
    ├── claude-results.csv
    ├── codex-results.csv
    ├── copilot-results.csv
    └── conformance-summary.json
```

## Running

```bash
# Run for a specific player
bash tests/conformance/run-claude.sh
bash tests/conformance/run-codex.sh    # run by Codex player
bash tests/conformance/run-copilot.sh  # run by Copilot player

# Compare (after all players have run)
python3 tests/conformance/compare-results.py
```

## Conformance rule

All semantic checks (event-type, derived-state, event counts, correlation-id consistency) must pass identically for all players. Allowed differences: player identity, UUIDs, timestamps, skill discovery path.
